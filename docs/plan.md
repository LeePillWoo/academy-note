# 학원 관리 앱 계획서 (학원노트)

- 작성일: 2026-10-30
- 수정일: 2026-10-30 (개발 방식을 "웹으로 먼저 만들고 APK로 감싸기"로 변경, 확인 사항 답변 반영)
- 상태: 확정

## 1. 목표

학부모가 자녀의 학원별 **납부 내역**, **출석**, **보강 일정**을 휴대폰 하나로 관리합니다.

- **자녀 여러 명**을 따로 관리합니다. (현재 2명)
- 서버 없이 데이터는 **휴대폰에만 저장**합니다.
- PC로 옮기거나 폰을 바꿀 때는 **백업 파일을 내보내고 가져오는 방식**을 씁니다.
- 수강료 방식, 보강 규칙, 알림처럼 학원마다 다른 것은 **앱 안에서 학원별로 설정**합니다.
- **휴대폰(삼성 인터넷 포함)과 PC에서 모두 정상적으로 보이고, 가로·세로 화면에 모두 대응**합니다.

## 2. 주요 기능

### ① 자녀 관리

- 자녀를 추가, 수정, 삭제합니다. 이름과 표시 색상을 정합니다.
- 화면 위쪽에서 **전체 / 첫째 / 둘째**를 골라 봅니다.
  - 전체: 모든 자녀의 수업, 납부, 보강을 함께 보여주고 자녀 색상으로 구분합니다.
  - 자녀 선택: 그 자녀의 학원만 보여줍니다.

### ② 학원 설정 (학원별로 따로)

모든 항목은 앱 안의 학원 설정 화면에서 정하고, 언제든 바꿀 수 있습니다.

**기본 정보**

| 항목 | 예시 |
|---|---|
| 학원 이름, 자녀, 표시 색상 | 수학학원 / 첫째 / 파랑 |
| 메모 | 원장 연락처, 환불 규정 등 |

**수업 일정**

| 항목 | 예시 |
|---|---|
| 수업 요일과 시간 (여러 개) | 월·수·금 17:00~18:30 |
| 적용 시작일 | 학기 중에 요일이 바뀌면 새 일정을 추가하고 시작일을 정합니다. 지난 기록은 그대로 남습니다. |

**수강료 방식** (셋 중 하나 선택)

| 방식 | 설정 항목 | 예시 |
|---|---|---|
| 월 단위 | 금액, 매월 납부일 | 25만 원 / 매월 5일 |
| 회차 단위 | 금액, 회차 수, 회차 세는 방법 | 20만 원 / 8회마다 |
| 기간 단위 | 금액, 개월 수, 첫 납부일 | 60만 원 / 3개월마다 |

- 회차 세는 방법: 출석과 보강 출석은 항상 셉니다. 결석은 "세지 않음 / 셈 / 보강을 안 하면 셈" 중에서 고릅니다.
- 수강료가 오르면 새 금액과 적용 시작일을 넣습니다. 지난 납부 기록은 그대로 남습니다.

**보강 규칙**

| 항목 | 선택지 |
|---|---|
| 보강 대상 | 결석, 휴강 (각각 켜고 끄기) |
| 보강 가능 기간 | 결석일로부터 N일 이내 / 같은 달 안 / 다음 달 말까지 / 기한 없음 |
| 보강 가능 요일과 시간 | 예: 토 10:00~12:00 (여러 개, 비워두면 제한 없음) |
| 보강 횟수 제한 | 한 달 최대 N회 / 제한 없음 |

### ③ 납부 관리

- 학원의 수강료 방식에 따라 납부 항목을 자동으로 만듭니다.
  - 월 단위: 매달 납부일에 만듭니다.
  - 회차 단위: 새 묶음의 첫 수업일을 납부 예정일로 잡고, **남은 회차(예: 3/8)**를 보여줍니다.
  - 기간 단위: N개월마다 만듭니다.
- 실제 납부일, 금액, 방법(카드/이체/현금), 메모를 기록합니다.
- 상태는 **납부 완료, 미납, 납부일 지남**으로 표시합니다.
- 교재비나 특강비 같은 추가 납부도 따로 넣을 수 있습니다.
- 월별, 자녀별, 학원별 납부 내역과 합계를 보여줍니다.

### ④ 출석 체크

- 수업 일정을 기준으로 달력에 수업일이 자동으로 표시됩니다.
- 날짜를 누르면 **출석, 결석, 휴강, 보강 출석** 중에서 고르고, 결석 사유를 메모할 수 있습니다.

### ⑤ 보강 관리 (핵심 기능)

결석이나 휴강을 기록하면 학원의 보강 규칙에 따라 보강 항목이 자동으로 생깁니다.

- **보강 가능 기간(○월 ○일~○월 ○일)이 자동으로 계산**됩니다.
- 상태는 **미정, 예정, 완료, 기한 만료, 보강 안 함**으로 관리합니다.
  - 예정: 날짜를 정하면 달력에 표시됩니다. 보강 가능 요일이 아니거나 횟수 제한을 넘으면 알려줍니다.
  - 완료: 실제로 간 날짜를 기록합니다.
  - 기한 만료: 기간이 지나면 자동으로 바뀝니다.
- 남은 보강 목록은 **마감이 가까운 순서**로 보여줍니다.

### ⑥ 홈 화면

- 오늘 수업과 예정된 보강
- 이번 달 미납 학원
- 마감이 일주일 이내인 보강
- 자녀를 고르면 그 자녀 것만 보여줍니다.

### ⑦ 알림 (서버 없이 폰 자체 알림)

일정에 맞춰 알림을 보내고, 종류마다 **언제, 몇 시에 받을지 자세히 정할 수 있습니다.**

| 알림 종류 | 기준 | 기본값 |
|---|---|---|
| 수강료 납부 | 납부 예정일 | 당일 오전 9시 |
| 미납 | 납부일이 지났는데 미납 | 다음 날 오전 9시 |
| 보강 예정 | 보강 예정일 | 전날 오후 8시 |
| 보강 마감 | 보강 가능 기간 마지막 날 | 3일 전 오전 9시 |
| 수업 | 수업 시작 시각 | 꺼짐 (켜면 1시간 전) |
| 백업 | 마지막 백업일 | 30일 지나면 오전 9시 |

- 종류마다 켜고 끌 수 있습니다.
- **며칠 전(당일 포함)과 몇 시**를 정합니다. 수업 알림은 "몇 분 전"으로 정합니다.
- 한 종류에 알림을 **여러 개** 걸 수 있습니다. 예: 납부 3일 전 + 당일
- 전체 기본값을 정하고, **학원마다 따로 바꿀 수 있습니다.** 예: 수학학원만 납부 알림을 3일 전으로
- **예정된 알림 목록** 화면에서 앞으로 울릴 알림을 미리 확인합니다.
- 알림을 누르면 해당 납부나 보강 화면으로 이동합니다.

### ⑧ 백업과 복원

- **내보내기**: 모든 데이터를 파일 하나(`.json`)로 저장합니다. 공유 기능으로 카카오톡 나에게 보내기, 메일, 구글 드라이브 등에 보낼 수 있습니다.
- **가져오기**: 백업 파일을 골라 복원합니다. 덮어쓸지 합칠지 선택합니다.
- **PC에서 보기**: 웹 버전을 PC 브라우저에서 열고 백업 파일을 불러와 확인합니다. 서버는 필요 없습니다.
- 백업한 지 오래되면 백업 알림을 보냅니다.

## 3. 기술 구성

### 개발 방식: 웹으로 먼저 만들고 APK로 감싸기

1. 처음에는 **웹 앱으로 개발**합니다. 코드를 고치면 브라우저에 바로 반영되므로 수정하면서 만들기에 좋습니다.
2. 알림과 백업이 필요한 단계에서 **Capacitor로 같은 코드를 APK로 감쌉니다.** 코드를 따로 옮기는 작업은 거의 없습니다.
3. 웹 버전은 그대로 **PC에서 백업 파일을 여는 페이지**로 씁니다.

웹 앱만으로 끝내지 않는 이유: 서버 없이는 "보강 마감 3일 전 오전 9시" 같은 예약 알림을 안정적으로 보낼 수 없습니다. 또 브라우저 데이터를 지우면 기록이 함께 사라질 수 있습니다.

| 구분 | 선택 | 이유 |
|---|---|---|
| 앱 방식 | **React + Capacitor** | 이미 설치된 Node.js를 쓸 수 있고 빠르게 만들 수 있습니다. 같은 코드로 웹과 APK를 모두 만듭니다. |
| 저장소 | 웹 단계: **IndexedDB (브라우저 저장)**<br>APK 단계: **SQLite (폰 내부 저장)** | 저장 기능을 한곳(저장소 계층)에 모아 두고, 실행 환경에 따라 저장 방식만 바꿉니다. 화면 코드는 고치지 않아도 됩니다. |
| 알림 | Capacitor Local Notifications | 서버 없이 폰 자체 알림을 씁니다. (APK 단계부터) |
| 백업 | Filesystem과 Share 플러그인 | 파일을 저장하고 다른 앱으로 공유합니다. |
| 코드 관리 | **Git (개인 저장소)** | 고치다가 잘못됐을 때 이전 상태로 되돌릴 수 있습니다. |
| 폰 미리 써보기 | 같은 와이파이로 접속 (기본)<br>GitHub Pages (선택) | 1~2단계에서 폰 브라우저로 테스트할 때 씁니다. PC에서 개발 서버를 켜고 폰에서 PC 주소로 접속하면 코드를 공개하지 않고도 테스트할 수 있습니다. |
| 빌드 | JDK 21과 Android SDK (명령줄 도구) | APK를 만드는 데 필요합니다. Android Studio는 없어도 됩니다. (3단계에서 설치) |

**화면 대응 (휴대폰, PC, 가로·세로)**

화면 너비에 따라 배치를 바꿉니다.

| 화면 | 배치 |
|---|---|
| 휴대폰 세로 | 한 줄 배치, 아래쪽 탭 메뉴 (홈 / 달력 / 납부 / 보강 / 설정) |
| 휴대폰 가로, 태블릿 | 두 칸 배치 (예: 왼쪽 달력, 오른쪽 그날의 수업과 보강) |
| PC | 왼쪽 메뉴와 넓은 본문, 달력과 목록을 한 화면에 함께 표시 |

지원 대상과 확인 방법은 다음과 같습니다.

- 지원 브라우저: **삼성 인터넷**, 크롬(휴대폰, PC), 엣지(PC)
- 처음부터 반응형으로 만들고, 기능을 하나 만들 때마다 휴대폰 세로·가로와 PC 크기에서 확인합니다.
- 실제 폰의 삼성 인터넷에서는 1단계부터 확인합니다. (같은 와이파이로 접속)
- APK는 삼성 인터넷이 아니라 안드로이드 기본 웹뷰(크롬 계열)로 화면을 그립니다. 그래서 3단계부터는 APK 화면도 따로 확인합니다.

삼성 인터넷에서 특히 주의할 점은 다음과 같습니다.

- **다크 모드**: 삼성 인터넷은 웹페이지 색을 강제로 어둡게 바꾸는 기능이 있습니다. 앱은 **항상 밝은 화면만** 쓰고(사용자 요청), 브라우저에 `color-scheme: only light`로 알려 강제로 어둡게 바꾸지 않게 합니다.
- **글자 크기 설정**: 브라우저에서 글자를 키워도 화면이 겹치거나 잘리지 않도록 높이를 고정하지 않습니다.
- **주소창**: 스크롤하면 주소창이 숨거나 나타나면서 화면 높이가 바뀝니다. 아래쪽 탭 메뉴가 가려지지 않도록 바뀌는 높이에 맞춥니다.
- **날짜 입력**: 브라우저 기본 날짜 입력창은 기기마다 모양이 다릅니다. 앱에서 만든 달력으로 날짜를 고릅니다.
- **화면 회전**: 가로·세로를 바꿔도 입력하던 내용이 사라지지 않게 합니다.

**알림 예약 방식**

- 앱이 꺼져 있어도 울리도록 알림을 폰에 미리 예약합니다.
- 안드로이드는 앱 하나가 예약할 수 있는 알림 수에 한도가 있습니다. 그래서 **앞으로 60일 치만 예약**하고, 앱을 열거나 일정과 설정을 바꿀 때마다 다시 예약합니다.
- 처음 실행할 때 **알림 권한**과 **정확한 시각 알림 권한**을 요청합니다. (Android 12 이상)
- 배터리 절약 모드에서는 알림이 몇 분 늦을 수 있습니다.

**주의할 점**

- 1~2단계(웹 단계)에서 입력한 데이터는 **테스트용**입니다. 실제 사용은 APK가 나오는 3단계부터 시작합니다.
- 무료 GitHub Pages는 저장소가 공개여야 합니다. 데이터는 폰에만 저장되지만 코드는 공개됩니다. 코드를 공개하고 싶지 않으면 GitHub Pages는 쓰지 않습니다.
- 정식 APK에는 서명 키 파일이 필요합니다. 이 키를 잃어버리면 이미 설치한 앱을 업데이트할 수 없으니 따로 보관해야 합니다. 서명 키는 Git에 올리지 않습니다.
- 사용자 폴더 경로에 한글이 있으므로 JDK, Android SDK, Gradle 캐시는 `90_Tools/` 아래 영문 경로에 둡니다.

## 4. 데이터 구조 (요약)

- **자녀**: 이름, 표시 색상, 순서
- **학원**: 자녀, 이름, 표시 색상, 메모
- **수업 일정**: 학원, 요일, 시작·종료 시각, 적용 시작일, 적용 종료일
- **수강료 규칙**: 학원, 방식(월/회차/기간), 금액, 납부일·회차 수·개월 수, 회차 세는 방법, 적용 시작일
- **보강 규칙**: 학원, 보강 대상(결석/휴강), 기간 기준, 보강 가능 요일과 시간, 횟수 제한
- **납부**: 학원, 종류(수강료/교재비/특강비/기타), 대상(월 또는 회차 묶음), 금액, 납부 예정일, 실제 납부일, 방법, 메모
- **수업 기록**: 학원, 날짜, 상태(출석/결석/휴강/보강 출석), 메모
- **보강**: 원래 수업 기록, 가능 시작일과 종료일, 예정일, 실제 간 날, 상태
- **알림 규칙**: 종류, 적용 범위(전체 기본값 또는 학원), 며칠 전 또는 몇 분 전, 시각, 켜짐 여부

## 5. 진행 단계

| 단계 | 내용 | 결과물 |
|---|---|---|
| 0 | 웹 프로젝트 만들기 (React), Git 저장소 만들기 | 브라우저에서 빈 화면이 뜨는 상태 |
| 1 | 자녀 관리, 학원 설정(수업 일정, 수강료 방식, 보강 규칙), 납부, 출석, 보강 기본 기능 | **첫 테스트용 웹 앱** |
| 2 | 홈 화면, 달력, 보강 기간 자동 계산과 만료 처리, 회차 단위 납부 계산, 알림 설정 화면과 예정된 알림 목록 | 테스트용 웹 앱 |
| 3 | 안드로이드 빌드 환경 설치 (JDK, Android SDK), APK로 감싸기, SQLite로 저장 전환, 백업과 복원, 실제 알림 예약 | **첫 테스트용 APK** (실제 사용 시작) |
| 4 | 디자인 다듬기, 아이콘, 서명된 정식 APK, PC용 웹 페이지 | **배포용 APK** |

- 1~2단계는 PC 브라우저와 폰의 삼성 인터넷(같은 와이파이로 접속)에서 확인합니다. 집 밖에서도 폰으로 써보고 싶으면 GitHub Pages에 올립니다.
- 화면 대응(휴대폰 세로·가로, PC)은 4단계로 미루지 않고 1단계부터 기능마다 함께 만듭니다. 4단계에서는 디자인만 다듬습니다.
- 알림 설정은 2단계(웹)에서 "예정된 알림 목록"으로 미리 맞춰 보고, 3단계에서 실제로 울리게 합니다.
- 3단계부터는 각 단계가 끝날 때마다 APK를 폰에 설치해 써봅니다.
- 단계마다 써본 의견을 다음 단계에 반영합니다.

## 6. 확인 사항 (2026-10-30 답변 완료)

- [x] 자녀는 몇 명인가? → **2명.** 자녀별로 따로 관리합니다. (2장 ①)
- [x] 실제 보강 규칙 예시 → **앱 안에서 학원별로 설정합니다.** (2장 ② 보강 규칙)
- [x] 수강료가 매달 같은가? → **학원마다 다릅니다.** 월, 회차, 기간 단위 중에서 학원별로 설정합니다. (2장 ② 수강료 방식)
- [x] 알림이 필요한가? → **필요합니다.** 납부일, 보강 전날 등 일정에 맞춰 보내고, 종류별로 자세히 설정합니다. (2장 ⑦)
- [x] 앱 이름과 색상 → 이름은 **학원노트**. 메인 색상은 파랑 계열로 시작하고, 둘 다 4단계에서 다시 정합니다.
