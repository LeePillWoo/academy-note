## 1. 결론: 합칠 수 있습니다

두 앱은 처음부터 같은 틀로 만들어서 옮기는 비용이 작습니다.

| 항목 | 학원노트 | 학습체크 | 합칠 때 |
|---|---|---|---|
| 라이브러리 | React 19, TS, Vite 8, react-router 8, idb 8 | 같음 | 추가 설치 없음 |
| 저장 방식 | `DataStorage` + IndexedDB `records` 한 저장소, 변경 묶음 저장 | 같은 구조 (DB 이름만 `study-check`) | 데이터 종류만 추가 |
| 아이 | `Child {name, color, order}` | 같은 모양 | **아이 목록 하나로 공유** |
| 날짜·요일 | `DateStr`, `Weekday 0~6` | 같음 | 그대로 |
| 디자인 | 남색, 카드, 메뉴 위치(세로 하단·가로 왼쪽), 항상 밝게 | 같은 값 | 공통 규칙 107개 중 9개만 값이 다름 |
| 인쇄 | 시간표 A4 세로, 안드로이드 인쇄 플러그인 | 요일별 A4 세로, 계획표·체크표 A4 가로 (브라우저만) | 용지 방향 처리 필요 |
| 테스트 | vitest 74개, Playwright 3화면 | vitest(week, weekStats), Playwright 3개 파일 | 같은 방식으로 옮김 |

합치면 생기는 좋은 점:
- 아이를 한 번만 등록하고, 홈에서 **오늘 수업 + 오늘 학습**을 함께 봅니다.
- 학원노트에 이미 있는 **백업·복원, 가족 공유, APK, 알림**을 학습체크가 그대로 씁니다. (학습체크의 '다음 할 일'이던 백업과 APK가 따로 할 필요 없이 해결됨)
- 가족 공유를 켜면 아이 태블릿에서 체크하고 부모 폰에서 진행을 볼 수 있습니다.

## 2. 합친 앱의 모습

### 메뉴
지금 학원노트 메뉴는 6개(홈, 달력, 시간표, 납부, 보강, 설정)이고 **학습**이 더해져 7개가 됩니다.

- **추천안**: 폰 세로 하단 메뉴는 **홈 · 달력 · 시간표 · 학습 · 납부 · 보강** 6개로 하고, **설정은 위쪽 막대 오른쪽 톱니 단추**로 옮깁니다. 가로·PC 왼쪽 메뉴에는 7개를 모두 둡니다.
- 다른 안: 하단에 7개를 모두 두기 (360px 폰에서 한 칸이 약 51px라 글자가 작아짐)
- → **사용자 확인 필요** (아래 7장 질문 1)

### 학습 화면 (`/study`)
- 학습체크 홈의 **주간 보드**를 그대로 옮깁니다: `‹ 주 ›` 이동, 보기 방식 **요일별(기본) | 계획표 | 체크표**, 마지막 보기 기억, 인쇄 단추.
- 과목 설정은 보드의 과목 이름을 눌러서 엽니다(`/study/subjects/:id`). 과목 목록·순서 바꾸기는 학습 화면 오른쪽 위 "과목" 단추로 엽니다. (학습체크의 '과목' 메뉴는 따로 두지 않음)
- **위쪽 아이 선택을 따릅니다.** (시간표에서 화면 안 아이 토글을 뺀 것과 같은 원칙)
  - 아이 하나를 고르면: 그 아이의 보드
  - **전체**를 고르면: 아이마다 카드 한 장씩 (이번 주 진행 막대, 오늘 할 것 n개 / 한 것 n개). 카드를 누르면 그 아이로 바뀌어 보드가 열립니다.

### 홈
- "오늘 수업" 카드 옆(폰은 아래)에 **"오늘 학습"** 카드를 추가합니다. 오늘 계획한 학습 내용이 아이별로 나오고, 바로 눌러 체크할 수 있습니다. 진행 `3/5`와 "학습 보드 열기" 링크.

### 설정
- 아이 관리는 학원노트 것을 씁니다. 아이를 지우면 학원·출석·납부와 함께 **과목·학습 내용·체크도** 지워진다고 안내 글을 고칩니다.
- 백업 파일과 가족 공유에 학습 데이터가 자동으로 포함됩니다.

### 이번에는 하지 않는 것 (나중에 선택)
- 달력에 학습 진행 표시 (칸이 복잡해짐)
- 과목과 학원 연결 (예: "영어" 과목 = ○○영어학원 숙제)
- 요일별 보기에 그날 학원 수업 시간 함께 보이기
- 학습 알림 (예: 저녁 8시 "오늘 학습 2개 남음", 기본 꺼짐)
- 지난 주들 기록 통계 (학습체크 '다음 할 일'에 있던 것)

## 3. 데이터 설계

### 추가하는 데이터 종류
`src/data/types.ts`의 `Collections`에 3가지를 더합니다.

```ts
/** 과목 (아이별). 학습 보드 왼쪽 묶음 */
interface Subject extends BaseRecord { childId: string; name: string; color: string; order: number }

/** 학습 내용 (과목 아래 한 줄). 계획 요일 기본은 월~금 */
interface StudyTask extends BaseRecord { subjectId: string; name: string; weekdays: Weekday[]; order: number }

/** 한 아이의 한 주 체크 묶음. id = `${childId}:${weekStart}` */
interface StudyWeek extends BaseRecord { childId: string; weekStart: DateStr; done: string[] /* `${taskId}:${date}` */ }
```

- 이름 `Task` 대신 `StudyTask`로 해서 학원 쪽 이름과 헷갈리지 않게 합니다. (저장 이름은 `subjects`, `studyTasks`, `studyWeeks`)
- `emptyDatabase()`, 백업의 `COLLECTION_LABELS`(과목, 학습 내용, 학습 체크), 연쇄 삭제(`cascade.ts`)를 함께 고칩니다.

### 체크를 '주 묶음'으로 바꾸는 이유
학습체크는 체크 한 칸이 기록 하나(`Check`)입니다. 혼자 쓰기에는 문제없지만 **가족 공유(Firestore)에서는 기록 수가 곧 비용**입니다.

- 아이 2명 × 학습 내용 8개 × 주 5일 × 52주 ≈ **1년에 체크 4,000개**
- Firestore는 앱을 열 때(30분 이상 쉬었다가) 가족 기록을 모두 다시 읽고, 무료 한도는 **하루 5만 번 읽기**입니다. 폰·태블릿 3대가 하루 4번씩 열면 1년 뒤 한도에 닿습니다.
- 주 묶음이면 **아이당 1년에 52개**라 걱정이 없습니다.

화면 쪽 사용법(`isDone(taskId, date)`, 체크·취소)은 그대로 두고 `checks.ts` 안쪽만 바꿉니다. 같은 주를 두 기기에서 **거의 동시에**(1~2초 안) 체크하면 나중 것만 남을 수 있습니다. 가족 앱에서는 드문 경우라 받아들입니다. (결정 기록에 적음)

### 연쇄 삭제
| 지우는 것 | 함께 지워지는 것 |
|---|---|
| 아이 | 학원 관련 전부(지금처럼) + 과목, 학습 내용, 주 묶음 |
| 과목 | 학습 내용, 그 내용의 체크(주 묶음에서 빼고 저장) |
| 학습 내용 | 그 내용의 체크(주 묶음에서 빼고 저장) |

### 버전이 섞일 때
- 백업 형식 버전은 1 그대로 둡니다. v1.0.0 앱은 모르는 데이터 종류를 건너뛰므로 새 백업도 열립니다(학원 기록만 들어감).
- 가족 공유에서도 v1.0.0 앱은 모르는 종류를 건너뜁니다. 다만 학습은 안 보이므로 **가족 폰을 모두 v1.1.0으로 맞추라고** 안내합니다.

### 인쇄 용지 방향
- 지금은 두 앱 모두 이름 없는 `@page`를 써서 합치면 부딪힙니다. **이름 있는 용지**로 나눕니다: 시간표·요일별 = `a4-portrait`, 계획표·체크표 = `a4-landscape`.
- APK의 인쇄 플러그인(`PrintPlugin.java`)은 지금 A4 세로로 고정입니다. **방향 옵션**을 더해 계획표·체크표는 `ISO_A4.asLandscape()`로 보냅니다. (`printPage(name, { landscape })`)

## 5. 기존 학습체크 데이터 옮기기

학습체크 기록은 **삼성 인터넷의 `leepillwoo.github.io` 저장 공간**(또는 PC의 `localhost:5180`)에 있고, 학원노트 APK는 저장 공간이 따로라 직접 읽을 수 없습니다.

- **기록이 거의 없다면**: 학원노트에서 과목만 다시 입력 (가장 간단)
- **옮겨야 할 기록이 있다면**:
  1. 학습체크 웹에 **"내보내기"** 단추를 추가합니다 (JSON 파일, `app: "study-check"`)
  2. 학원노트 '백업과 복원'의 가져오기가 학습체크 파일도 알아보게 합니다.
  3. **아이는 이름으로 짝을 맞춥니다.** 같은 이름이 있으면 그 아이에 붙이고, 없으면 새 아이로 만듭니다. 체크는 주 묶음으로 바꿔 넣습니다. 가져오기 전에 요약(아이 n명, 과목 n개, 체크 n개)을 보여줍니다.
- → **사용자 확인 필요** (질문 3)
