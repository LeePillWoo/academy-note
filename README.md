# 학원 관리 앱 (academy-note)

학부모가 자녀의 학원별 납부 내역, 출석, 보강 일정을 관리하는 안드로이드 앱입니다.
서버 없이 폰에 저장하고, 백업 파일로 PC와 주고받습니다.

- 계획서: [docs/plan.md](docs/plan.md)
- 개발 중 정한 것들: [docs/decisions.md](docs/decisions.md)
- 자녀 2명을 따로 관리하고, 수강료 방식, 보강 규칙, 알림은 학원별로 앱 안에서 설정합니다.
- 휴대폰(삼성 인터넷 포함)과 PC 모두, 가로·세로 화면에 대응합니다.
- 개발 방식: 웹 앱으로 먼저 만들고, 3단계에서 Capacitor로 APK로 감쌉니다.

## 내려받기 (안드로이드)

- **최신 버전 APK**: https://github.com/LeePillWoo/academy-note/releases/latest/download/academy-note.apk
- 버전별 목록과 바뀐 점: https://github.com/LeePillWoo/academy-note/releases

폰에서 위 주소를 열어 내려받고, 파일을 열어 설치합니다. ("출처를 알 수 없는 앱 설치"를 물으면 허용) 지금은 테스트용(디버그 서명) 빌드입니다.

### 새 버전 올리는 방법 (개발용)

1. `android/app/build.gradle`의 `versionCode`를 1 올리고 `versionName`과 `package.json`의 `version`을 새 버전으로 바꿉니다.
2. `npm run apk`로 빌드합니다.
3. 커밋·푸시한 뒤, 파일 이름을 **`academy-note.apk`로 똑같이** 해서 릴리스를 만듭니다. 이름이 같아야 위의 "최신 버전" 주소가 새 파일을 가리킵니다.
   ```
   cp apk/academy-note-debug.apk apk/academy-note.apk
   gh release create v1.0.1 apk/academy-note.apk --target main --title "학원노트 v1.0.1" --notes "바뀐 점"
   ```
4. 업데이트 설치는 **같은 서명 키**로 만든 APK만 됩니다. 디버그 키 백업은 `90_Tools/signing-backup/debug.keystore`에 있습니다.

## 가족 공유를 쓰려면

기본은 혼자 쓰기이며 서버에 아무것도 보내지 않습니다. 여러 폰이 같은 기록을 보려면 Firebase 프로젝트가 필요합니다(무료).

1. Firebase 콘솔에서 프로젝트를 만들고 **Authentication → 익명** 로그인과 **Firestore Database(서울, asia-northeast3)**를 켭니다.
2. 웹 앱을 추가하고 `firebaseConfig` 값을 `.env` 파일의 `VITE_FIREBASE_CONFIG`에 JSON 한 줄로 넣은 뒤 다시 빌드합니다. (`.env.example` 참고) 또는 앱의 설정 > 가족 공유 화면에 그대로 붙여넣어도 됩니다.
3. Firestore **규칙**에 `firestore.rules` 내용을 붙여넣고 게시합니다. (테스트 모드는 30일 뒤 막힙니다.)
4. 한 폰에서 "가족 코드 만들기", 다른 폰에서 "가족 코드로 참여"를 하면 됩니다.

## 실행 방법

처음 한 번만 라이브러리를 설치합니다.

```
npm install
```

| 명령 | 용도 |
|---|---|
| `npm run dev` | PC에서 개발 서버를 켭니다. 브라우저에서 `http://localhost:5173` 을 엽니다. |
| `npm run dev:phone` | 폰에서도 접속할 수 있게 개발 서버를 켭니다. 폰을 PC와 같은 와이파이에 연결하고, 삼성 인터넷에서 화면에 나오는 `Network:` 주소(예: `http://172.30.1.8:5173`)를 엽니다. |
| `npm run build` | 배포용 파일을 `dist/` 폴더에 만듭니다. |
| `npm run preview` | 만든 배포용 파일을 미리 봅니다. |
| `npm test` | 계산 테스트. 날짜, 금액, 입력 검사 같은 계산이 맞는지 확인합니다. |
| `npm run apk` | 디버그 APK를 만듭니다. (웹 빌드 → Capacitor 동기화 → Gradle) 결과는 `apk/academy-note-debug.apk` 입니다. JDK·SDK·Gradle은 `90_Tools/`에 있습니다. |
| `npm run test:e2e` | 화면 테스트. PC의 Edge로 휴대폰 세로·가로, PC 크기에서 기능을 자동으로 눌러 확인합니다. |

- `npm run dev:phone`을 처음 실행하면 Windows 방화벽 창이 뜰 수 있습니다. **개인 네트워크**만 허용합니다.
- 개발 서버가 켜져 있는 동안 코드를 고치면 PC와 폰 화면에 바로 반영됩니다.

## 폴더 구조

```
academy-note/
├─ docs/            계획서, 설계 문서
├─ public/          아이콘 같은 정적 파일
├─ src/
│  ├─ data/         저장소 계층과 데이터 기능 (화면은 이곳만 통해 저장)
│  ├─ components/   여러 화면에서 쓰는 부품 (화면 제목, 색 고르기, 아이콘)
│  ├─ layout/       화면 뼈대 (메뉴, 위쪽 막대, 자녀 선택)
│  ├─ pages/        화면 (홈, 달력, 납부, 보강, 설정)
│  ├─ hooks/, utils/  작은 도우미 기능
│  ├─ App.tsx       화면 주소 연결
│  ├─ main.tsx      시작 파일
│  └─ index.css     색상, 반응형 배치
├─ tests/e2e/       화면 테스트
├─ index.html
└─ package.json
```
